&par Example Description

This example shows how to configure the TMR5 peripheral to generate PWM signals
with different duty cycles.
The TMR5 waveform can be displayed using an oscilloscope.

using TMR5 CHANNEL1(PA1) to output PWM

&par Directory contents

  - TMR/TMR_PWMOutput/Source/main.c                 Main program
  - TMR/TMR_PWMOutput/Source/apm32f4xx_int.c        Interrupt handlers

&par IDE environment

  - MDK-ARM V5.40
  - EWARM V8.50.5.26295
  - ECLIPSE-EMB V4.24.0

&par Hardware and Software environment

  - This example runs on APM32F403 TINY Devices.
